# Бриф

## Задача пользователя

Составить список перед походом в магазин, указать нужное количество товаров и отмечать покупки по мере их совершения.

**Платформа:** iOS.

## Основной сценарий

Добавить товар → указать количество → увидеть его в списке → отметить купленным.

## Возможности

- Один список с названием, количеством и состоянием покупки каждой позиции.
- Добавление через «+» на нижней панели. В пустом списке также доступна кнопка добавления первой позиции.
- Отметка покупки отдельной кнопкой. Купленные товары различаются значком и зачёркиванием.
- Карточка товара с изменением названия и количества, сбросом несохранённых правок и удалением.
- Настройки на нижней панели с выбором темы. Добавление и настройки открываются отдельными окнами.
- Сохранение изменений на устройстве между запусками.

## Границы прототипа

Используются демонстрационные товары. Реальные аккаунты, сервер, платежи, совместный доступ, синхронизация и публикация не входят в задачу. Продолжение разработки согласуется отдельно.

## Критерии готовности

- Основной сценарий работает, количество сохраняется, товар можно изменить и удалить.
- Пустое название и название из пробелов не сохраняются. Пустой список объясняет, как добавить товар.
- Форма остаётся доступной при открытой клавиатуре, последняя строка списка — над нижней панелью.
- Команда проверяет приложение и показывает его владельцу. Приёмку подтверждает владелец.
