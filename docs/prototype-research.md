# Исследование интерфейса

## Цель

Подготовить простой список покупок для iOS: быстро добавить товар с количеством, найти его в списке и отметить покупку. Исследование поддерживает этот сценарий и не расширяет границы прототипа.

## Наблюдения из аналогов

- **Добавление должно быть коротким.** В AnyList товар можно вводить из списка. Для нашего прототипа это аргумент в пользу заметного действия добавления и простой формы без лишних полей.
- **В строке достаточно главного.** В AnyList дополнительные сведения о товаре доступны отдельно. Название и количество оставляем в списке, редактирование — в карточке.
- **Количество важно при покупке.** Возможности AnyList учитывают количество товара. В прототипе достаточно положительного целого числа, без цен, магазинов и категорий.

## Решения для прототипа

- По решению владельца «+» и настройки расположены на нижней панели, дублирующие кнопки сверху убраны. Источники каталога компонентов сохранены для отдельной демонстрации.
- В строке видны название, количество и отдельная кнопка отметки. Покупка различается значком и зачёркиванием. Нажатие на название открывает карточку.
- Форма добавления содержит название и количество, начиная с 1. Пустой ввод объясняет ошибку. После сохранения товар появляется в списке.
- В карточке можно изменить название и количество, сбросить несохранённые правки или удалить товар.
- Пустой список предлагает добавить первую позицию. Нижняя панель и клавиатура должны оставлять нужные действия доступными. Подписи и состояние кнопок должны быть понятны при озвучивании интерфейса.
